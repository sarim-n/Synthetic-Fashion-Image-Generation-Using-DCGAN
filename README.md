# Synthetic Fashion Generation using DCGAN

## Overview
A lightweight Generative AI system built using PyTorch and Deep Convolutional Generative Adversarial Networks (DCGAN) to learn the data distribution of the Fashion-MNIST dataset and synthesize realistic $28 \times 28$ grayscale fashion item images (e.g. shoes, shirts, dresses).

## Architecture Overview
The system consists of two primary networks trained in an adversarial framework:
- **Generator**: Maps a 100-dimensional random Gaussian noise vector $z \sim \mathcal{N}(0, I)$ to a synthetic $28 \times 28 \times 1$ image using linear projection, transposed convolutions, Batch Normalization, and ReLU/Tanh activations (778,240 parameters).
- **Discriminator**: A convolutional binary classifier that distinguishes between real Fashion-MNIST images and synthetic images generated by the Generator, using Conv2d layers, LeakyReLU activations, and BatchNorm (138,689 parameters).

## Technology Stack
- **Core Language**: Python 3.11
- **Deep Learning Framework**: PyTorch (CUDA 12.1), Torchvision
- **Web Dashboard**: Flask, HTML5, CSS3, JavaScript
- **Numerical & Scientific Utilities**: NumPy, Matplotlib, Pillow
